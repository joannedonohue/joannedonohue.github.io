04 / TURN INSIGHT INTO ACTION

What should the team do next?

Inside the product: data, orchestration & evaluation

This concept explores a category manager’s weekly performance review. The analysis sequence runs local functions over three synthetic datasets. It illustrates the workflow of an analytics agent; it uses synthetic data rather than live retailer or brand systems.

Metric contract: Sales = average selling stores × units per selling store per week × 8 weeks × realized price per unit. Units use one consistent pack size. Distribution is an unweighted store count, not ACV. Price includes promotions; changes in the real world would require pack-size and mix normalization.

Production design: A read-only agent would query governed sales data, run deterministic calculations, retrieve dated external evidence, and pass supported findings to a language model. Every conclusion would link to a query or source. Missing data would remain unknown, and a person would approve budget or price changes.

Evaluation: Test arithmetic reconciliation, source freshness, unsupported causal claims, and whether analysts can reach a useful decision faster. Validate recommendations through store-level tests before claiming sales lift.
